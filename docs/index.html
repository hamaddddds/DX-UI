DX-UI for Roblox

The DX-SR hub interface library. You create one window, add tabs, and then call an element for each feature. Every element supports Lucide icons by name, saves to configs through its Flag, and animates out of the box. The API follows WindUI, so existing hubs move over with few changes.

  • 1 file, no dependencies
  • 14 elements
  • 4 built-in themes
  • Lucide icon set

Installation

Load the library once at the top of your script. It returns the DX table that every other call starts from.


    


    

      
Window

      
The window holds the topbar, the sidebar and the tab pages. It opens with a pop-in animation, can be dragged by the topbar, resized from the bottom-right corner, and is hidden or shown with the toggle key.

      
Every instance is named after what it holds, such as [Group] Main, [Tab] Farming, [Section] Auto Farm and [Toggle] Auto Office Worker, so the explorer reads like a set of folders.

Sidebar & Tab

      
Window:Section creates a collapsible group in the sidebar, and Group:Tab adds a tab inside it. Use Window:Tab for a tab without a group. The first tab you create opens automatically. The sidebar search matches tab titles and the titles of elements inside each tab.

Notify

      
Toasts slide in from the bottom right, or drop down from the top center with Placement = "Top". Each one shows a seconds countdown and a countdown bar, stacks with the others, and the close button dismisses it early. Toasts scale down on small screens (75% minimum) so they fit on mobile.

Every element with a Flag is saved. Files go to Folder/configs/name.json. Loading runs each element's callback, so toggles start their loops and colors apply right away.

Glass

      
Glass mode turns the window, element cards, fields, notifications and dialogs translucent with a soft sheen, so the game shows through. Roblox cannot blur what is behind a GUI, so in game the glass is see-through without the blur this page adds. Switch it on with the Glass button at the top, or the floating card on the window preview.

      

      
Glass = trueWindow:SetGlass(bool)DX:SetGlass(bool)DX.Glass

    


    

      
Cursor

      
Some games hide the mouse or draw their own crosshair, which makes the menu hard to click. While the mouse is over the window, the open button or a dialog, DX-UI hides the game cursor and draws its own arrow on top. It gives control back when the mouse leaves. Read Window.Hovering to hide a game crosshair yourself, and pass Cursor = false to turn it off.

      

    


    

      
Mobile

      
The window measures the screen when it opens. If it does not fit, it scales down to fit, but never below 0.45. It measures again when the screen rotates or resizes. Dragging, sliders, the colorpicker and the floating open button all work with touch. DX.IsMobile is true on a touch screen without a keyboard.

      

      
Scale = numberWindow:SetScale(n | nil)Window.ScaleDX.IsMobile

    


    

      
Icons

      
Any option named Icon accepts a name from lucide.dev/icons, an rbxassetid:// string, an rbxthumb:// string or a plain asset id number. Lucide icons follow the theme colors. Image icons keep their own colors.
